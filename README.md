# Taipei parking live status — dormant bootstrap

This public repository contains a one-shot publisher for Taipei parking status. The schedule must remain off until the release gates are met. It does not access D1, TDX, or the application database.

The runner derives geometry from the pinned committed reader artifact and joins a public Taipei status feed. See [geometry provenance](docs/GEOMETRY-PROVENANCE.md) for the offline source-to-artifact reconstruction, [dry-run plan](docs/DRY-RUN-PLAN.md), [reader budget](docs/READER-BUDGET.md), [Viv's steps](docs/VIV-STEPS.md), [handoff](STATUS.md), and [attribution](DATA-ATTRIBUTION.md). The upstream copied files and source commit are recorded in [PROVENANCE.json](PROVENANCE.json).

LIVE-7Q1-SYNC vendors PR #46 at `0e2f3f7a90532f2cf1bdb2c7caaea683c07b140c`: shared TCMSV road-name normalization and collision checks require one geometry, one source key and one provider alias per match. `npm run replay:dry-run` runs the [hash-pinned investigation replay](tools/live-status/fixtures/live7/README.md) entirely offline, without credentials or publication. It asserts **21,332 matched / 30,136 unmatched / 68 ambiguous** geometry rows and **21,332 matched / 7,812 unmatched / 278 ambiguous** source cells across 32 shards. These exactly match the merged replay and `/workspace/live7/normalization-replay.json`. Normalization recovers 4,499 matches while four previously matched keys become ambiguous, for a net gain of 4,495. The replay also runs in `npm test`; ambiguous rows withhold provider aliases, statuses and clocks.

With Node 24.22.1, run `npm ci`, `npm test`, `npm run verify:provenance` (requires the private checkout at `/workspace/taipei-parking-alert` and the hash-recorded local geometry inputs; see the geometry provenance instructions), and `npm run dry-run`. Production requires no npm install. Fixture dry-run reads no network or secrets. The workflow schedule is guarded by `LIVE_SCHEDULE_ENABLED == 'true'`; keep that variable unset until separately authorized. Manual dispatch defaults to dry-run. A real run additionally requires the exact public-repository allowlist and four Actions secrets: `R2_ACCOUNT_ID`, `R2_BUCKET`, `R2_ACCESS_KEY_ID`, and `R2_SECRET_ACCESS_KEY`. Publish preflight rejects missing or blank R2 settings before any network call, naming only the missing settings. Dry-run requires no R2 settings. The current wrapper has no GC; do not enable sustained publication without a reviewed GC solution.
